# Trakt Month Calendar 1.0.0

The first release of Trakt Month Calendar adds a monthly grid to Trakt Calendar and Releases.

## Features

- Monthly calendar with chronological loading.
- Previous Month, Next Month and Jump to Current Week controls.
- Switching between Month View and Trakt's Original View.
- Native Trakt images, watched controls, card menus and information drawers.
- Local processing without a separate Trakt API key, analytics or persistent extension storage.

## Install

1. Download the attached `trakt-month-calendar-v1.0.0.zip`.
2. Extract it into a folder you will keep on your computer.
3. Open `chrome://extensions` and enable **Developer mode**.
4. Click **Load unpacked** and select the folder containing `manifest.json`.
5. Open or reload Trakt Calendar or Releases.

The repository README contains usage and update instructions. The privacy policy is available in the repository's `PRIVACY.md` file.
